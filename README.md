# 📋 Aplicación de Lista de Tareas

## 🧠 Descripción
Esta aplicación permite gestionar una lista de tareas de manera sencilla. El usuario puede agregar, visualizar y eliminar tareas mediante una interfaz gráfica desarrollada en Python.

---

## ⚙️ Tecnologías utilizadas
- Python
- Tkinter

---

## 📁 Estructura del proyecto
- main.py → archivo principal
- modelos/ → manejo de datos
- servicios/ → lógica del sistema
- ui/ → interfaz gráfica

---

## 🚀 Cómo ejecutar el programa
1. Abrir el proyecto en Python
2. Ejecutar el archivo `main.py`

---

## 🎯 Funcionalidades
- Agregar tareas
- Mostrar lista de tareas
- Eliminar tareas
